## Overview

Run a package's distribution contract tests against an isolated copy of its bundle.
The package must declare a `test:distribution` npm script. Its tests load the
absolute `ACTION_ENTRYPOINT` path supplied by this action instead of source.
Dependencies needed by the tests may be installed in the package; the copied
bundle has no adjacent node_modules. Temporary files are removed even on failure.
Use the [test workflow](../../../.github/workflows/test-action-distributions.md)
to discover packages, install dependencies and verify checked-in distributions.

## Usage

```yaml
- uses: hoverkraft-tech/ci-github-common/actions/quality/test-action-distribution@ce885f8dd6bf7191a79e3eebdf37bca805d40932 # 3.0.0
  with:
    # Package directory containing the distribution contract test script.
    # Default: `.`
    working-directory: .

    # Bundle directory relative to the package, containing index.js.
    # Default: `dist`
    output-directory: dist
```
