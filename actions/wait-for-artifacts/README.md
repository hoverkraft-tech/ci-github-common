## Overview

Wait until every requested artifact ID is discoverable in the current workflow run.
Uses the artifact service used by download-artifact and deploy-pages, without
additional GITHUB_TOKEN permissions or runtime dependency installation.
Missing IDs retry with exponential backoff, up to 61 seconds of waiting.
Invalid IDs and service errors fail immediately. Only GitHub.com is supported.

Wait for uploaded artifacts before downloading or deploying them.
Use the IDs returned by upload-artifact or upload-pages-artifact.

```yaml
- uses: hoverkraft-tech/ci-github-common/actions/wait-for-artifacts@<commit-sha>
  with:
    artifact-ids: ${{ steps.upload.outputs.artifact-id }}
```
