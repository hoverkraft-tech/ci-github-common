# Need fix to Issue

Creates issues from TODO/FIXME comments with [Todo to Issue Action](https://github.com/alstr/todo-to-issue-action), then categorizes and deduplicates open issues carrying the `need-fix` label. Used by the [Need fix to Issue workflow](../../.github/workflows/need-fix-to-issue.md).

## Behavior

- Scans the commit diff for `TODO:` and `FIXME:` comments. Both receive the `need-fix` label, in addition to `help wanted` for `TODO:` and `bug` for `FIXME:`.
- Assigns the organization's `Bug` issue type to untyped issues. Existing types are preserved. Personal repositories skip typing; an unavailable `Bug` type produces a warning without preventing duplicate cleanup.
- Keeps the oldest open issue with an exact matching title and source file. Source links must be standalone URLs into the current repository, with a full commit SHA and a line anchor as generated by `alstr/todo-to-issue-action`. Commit and line changes do not affect matching.
- Comments `Duplicate of #<original>` on newer duplicates and closes them with a link to the original. Reruns reuse an existing matching comment.
- Excludes pull requests and leaves issues without recognized source links open. Only issues labeled `need-fix` are considered; applying that label opts an issue into management.
- Propagates API failures, including permission errors, so failed runs can be retried.

## Usage

Use the [reusable workflow](../../.github/workflows/need-fix-to-issue.md) to include checkout and runner configuration, or call this composite action after checking out the repository. The job requires `contents: read` and `issues: write` permissions. Both steps use the job's `GITHUB_TOKEN`. The action has no outputs.

The optional inputs select the commit diff when running manually:

| Input               | Description                                                                                       | Required |
| ------------------- | ------------------------------------------------------------------------------------------------- | -------- |
| `manual-commit-ref` | The SHA of the commit to get the diff for.                                                        | No       |
| `manual-base-ref`   | An earlier SHA to compare against. Defaults to the commit immediately before `manual-commit-ref`. | No       |

## Development

Run the tests with Node.js as specified in [package.json](package.json):

```sh
npm test --prefix actions/need-fix-to-issue
```

Tests mock the GitHub APIs and do not modify real issues.
The [CI workflow](../../.github/workflows/__test-action-need-fix-to-issue.yml) uses shared Node.js CI and runs `test:ci` to generate an LCOV report at `coverage/lcov.info` inside the action directory.
